# Refresh

Treat the existing Staging Wiki as useful context, not as authority.

1. Reinspect the complete Repository Snapshot Set and reconsider every existing page against current
   source.
2. Preserve structure and prose that remain useful and accurate. Correct stale facts and citations;
   add pages for newly important reader questions; remove or merge pages whose purpose disappeared.
   Prefer directory paths (`modules/`, `flows/`, …) for related concept pages. Do not maintain
   hand-written `index.md` files as durable TOC — the product regenerates directory listings
   mechanically after write/repair and at publish.
3. After every page-set change, ensure concept pages still cross-link correctly and the directory
   layout still exposes hierarchy; no old statement survives merely because its source file was
   untouched.
4. Proceed to the review reference after the whole Wiki reflects the current snapshot.

Refresh is complete when every retained concept page still earns its place, all current important
ideas are navigable via the narrative overview and multi-level mechanical indexes, and no content
depends on the previous publication being correct.
