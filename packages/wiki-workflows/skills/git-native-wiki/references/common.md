# Wiki Run Contract

Work only in the current Wiki workspace. Use declared source projects as the
only source of truth. Never create source copies, snapshots, manifests, or
workflow-state files.

All source references are workspace-relative `path#Lx-Ly` ranges. User-facing
Wiki content must be written in {{language}}. Generated pages belong only under
`wiki/`; directory indexes are generated by the extension.

Keep claims tied to inspected source evidence. Do not cite absolute paths,
temporary paths, `sources/`, `inputs/`, or source IDs.
