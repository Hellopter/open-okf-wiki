# Planning

Inspect the declared source projects before deciding the page set. Plan pages
that answer a distinct reader question and cite the source ranges needed to
write them. Request research only for independent, evidence-heavy gaps; do not
create overlapping scopes or more than four scopes.

When the plan is complete, call `wiki_submit_plan` exactly once. Its fields are
the control protocol for the workflow. Do not put the plan in a JSON response.
