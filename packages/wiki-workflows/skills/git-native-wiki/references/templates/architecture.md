# Architecture Page Skeleton

Use only for an Architecture page selected by the finalized WikiSpec. Structure
the page around these sections when source evidence exists:

1. Scope and architectural responsibility
2. Components and ownership boundaries
3. Verified interaction or dependency paths
4. Operational or failure boundaries
5. Links to component and flow pages

Use a `flowchart` for three or more meaningful component boundaries. Use a
`sequenceDiagram` only when a specific request, command, or event path needs
ordered interaction. Explain diagram scope and cite evidence adjacent to it.
