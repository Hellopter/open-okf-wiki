# Concept Page Skeleton

Use only for a Concept page selected by the finalized WikiSpec. Structure the
page around these sections when source evidence exists:

1. Definition and scope
2. Why the concept exists
3. Rules, invariants, or lifecycle
4. Where the concept is used
5. Links to implementing modules and flows

Use `erDiagram` only when source-backed persisted entities and their
relationships are central to the concept. Use `stateDiagram` only when the
concept has explicit source-backed states and transitions. Do not diagram an
abstract concept without a verified relationship to explain.
