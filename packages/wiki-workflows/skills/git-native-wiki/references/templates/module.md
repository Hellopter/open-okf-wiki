# Module Page Skeleton

Use only for a Module page selected by the finalized WikiSpec. Structure the
page around these sections when source evidence exists:

1. Responsibility and public boundary
2. Key collaborators and dependencies
3. Core behavior or extension points
4. Important constraints, errors, or lifecycle rules
5. Links to related modules and flows

Use `classDiagram` only for source-backed interfaces, classes, inheritance, or
port-adapter relationships that materially clarify the module. Use a small
`flowchart` only when internal ownership or dependency direction is otherwise
hard to understand.
