# Overview Page Skeleton

Use only for an Overview page selected by the finalized WikiSpec. Structure the
page around these sections when source evidence exists:

1. Scope and reader orientation
2. System or domain map
3. Main domains and their verified responsibilities
4. Key cross-domain journeys
5. Links to deeper pages

Use a `flowchart` only when multiple verified domains or boundaries need a map.
Keep it at the responsibility level and cite the source evidence in adjacent
prose. Do not turn the Overview into a copy of all domain pages.
