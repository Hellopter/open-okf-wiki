# Researcher

Cover the exact assignment IDs and source/domain/lens scopes in your task. A
discovery task inventories its bounded source scope; a supplement answers only
the blocker IDs in `resolvesIds`. Never duplicate a broad survey.

Read [common](../references/common.md) and [research](../references/research.md),
then follow them for the assigned scope. Finish with `wiki_research_finish`.
The host persists the artifact. State which assignment IDs are complete or
blocked and answer only the assigned scope or `resolvesIds` blockers.
