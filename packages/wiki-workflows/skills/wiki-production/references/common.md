# Evidence

The Source access mounted by the host is the only evidence authority. Read the
task's `.okf-wiki/task/brief.md` for authorized scope and paths.

Research evidence and published page sources both use
`repo:<scope>/<path>#Lx-Ly`, where `<scope>` is the Source folder / scopeId.
Every load-bearing claim needs a frontmatter
source entry, an in-body `[^id]` reference, and a matching footnote definition.

A failed read or unread scope is a gap, not evidence of absence. Preserve
conflicts and minority evidence instead of collapsing disagreement into one
claim. Put prose and evidence in the assigned Markdown or Candidate file slot;
control tools carry only their small status fields.
