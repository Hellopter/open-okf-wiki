# Architecture Page Skeleton

Use only for an Architecture page. Consider these sections when verified source
supports them. Ordering is optional guidance only; write a section only when
source supports it.

1. Scope and architectural responsibility
2. Components and ownership boundaries
3. Verified interaction or dependency paths
4. Data or control flow across components (when distinct from a Flow page)
5. Operational or failure boundaries
6. Links to component and flow pages
