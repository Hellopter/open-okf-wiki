# Models Page Skeleton

Use for `<domain>/<concept>/models.md`, or `models/<slug>.md` when one file
cannot hold the verified models. Consider these sections when source supports
them:

1. Model purpose and ownership
2. Fields, relationships, and identity
3. Constraints and invariants
4. Creation, mutation, and deletion lifecycle
5. Where the models are used
6. Links to flows, states, and modules
