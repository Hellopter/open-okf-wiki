# Sequences Page Skeleton

Use only for `<domain>/<concept>/sequences.md` when multiple interactions
overflow `flows.md`. Consider these sections when source supports them:

1. Why these interactions are separate from `flows.md`
2. Actors and messages for each overflow interaction
3. Ordering, guards, or protocol rules
4. Failure, timeout, or retry behavior
5. State or data effects
6. Links back to `flows.md` and the owning modules
